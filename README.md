# My Portfolio (React + Vite)

## Run it
```
npm install
npm run dev
```
Open the link it prints (usually http://localhost:5173).

## Make it yours
1. Open `src/data.js` and replace the sample text with your own. All content lives there.
2. Put your resume at `public/resume.pdf` and your photo at `public/me.jpg` (then set `photo: "/me.jpg"` in data.js).
3. Project screenshots go in `public/projects/` and are linked via `image: "/projects/name.png"`.
4. Change colors at the top of `src/styles.css` (the `:root` block).
5. Change the page title in `index.html`.

## Publish it (free)
```
npm run build
```
Upload the `dist` folder to Vercel, Netlify or GitHub Pages.
